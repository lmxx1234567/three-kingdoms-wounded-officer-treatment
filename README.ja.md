# 傷兵療養任務

この MOD は『Total War: THREE KINGDOMS 1.7.x』のキャンペーンに、永久負傷した武将を治療する2つの任務を追加します。

## Steam Workshop

- [メイン MOD：傷兵療養任務](https://steamcommunity.com/sharedfiles/filedetails/?id=3793327386)
- [英語翻訳](https://steamcommunity.com/sharedfiles/filedetails/?id=3793327818)
- [日本語翻訳](https://steamcommunity.com/sharedfiles/filedetails/?id=3793327897)
- [韓国語翻訳](https://steamcommunity.com/sharedfiles/filedetails/?id=3793328007)

翻訳パックはメイン MOD を必要とします。先にメイン MOD を購読し、翻訳パックは1つだけ有効にしてください。
