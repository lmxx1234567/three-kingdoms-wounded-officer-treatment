# 傷兵療養任務

この MOD は『Total War: THREE KINGDOMS 1.7.x』のキャンペーンに、永久負傷した武将を治療する2つの任務と華佗のランダムイベントを追加します。負傷武将を含む軍が都市に駐屯して兵を補充していると、華佗が来訪することがあります。2000金で即時治療できるほか、原版の固有品が未所有なら1000金で華佗を登用するか、『青嚢書』を没収できます。没収すると勢力全体の満足度が5ターンの間10低下します。登用または没収後、その勢力では以後、特殊選択肢のない一般の名医が来訪します。
